# ChordSlop

A Renoise tool built from the [ReSlop](https://github.com/dac514/reslop) starter kit.

## What it does

Adds **Tools > ChordSlop...** to the main menu (and a bindable shortcut under
*Global > Tools > Show ChordSlop*). The dialog shows the current song name, BPM
and track count, keeps a greeting in the tool preferences, and prints it to the
status bar.

## Install

Drag `com.dac514.ChordSlop.xrnx` onto Renoise, or copy this folder into the
`Scripts/Tools` folder of your Renoise preferences directory.
